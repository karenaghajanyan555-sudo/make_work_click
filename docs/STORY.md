# Story rules

Every video is one clear idea told as a transformation. If the idea needs two sentences
to state, it is two videos.

## Shape (≈20 s)
| Beat | Time | Job |
|---|---|---|
| Hook | 0–2 s | A specific, slightly uncomfortable truth. Frame 0 already shows it (QA checks frame 0 is not empty). |
| Problem | ~2–6 s | One problem, shown not explained (scattered to-dos, overdue tags). |
| Solution | ~6–12 s | The system, visually understandable without narration. |
| Transformation | ~12–16 s | The satisfying moment it runs by itself (the click, the flip, Sent ✓). |
| Ending + CTA | last ~3 s | A memorable line + brand lockup + one ask ("Follow for systems that work"). |

## Script
- Spoken English, second person, present tense. Short sentences. Concrete nouns
  (subscriber, welcome email, Thursday 9:00) over abstractions (engagement, workflows).
- Narration says what the picture cannot; never describes what is already on screen.
- Banned: "In today's fast-paced world", "Are you tired of", "game-changer", "unlock",
  "supercharge", "leverage", rhetorical lists of three adjectives, any fake statistics.
- No claims about real products, prices or results. No affiliate links, ever.
- The ending line should rhyme with the hook (memory → "Let the system remember").

## Captions (on-screen text)
- Phrase-based, never word-by-word. One phrase on screen at a time; ≤ 7 words per phrase;
  display role ≤ 3 lines, title role ≤ 2 lines.
- Markup: `*word*` emphasis (serif italic), `**word**` signal (serif italic + lime),
  `\n` line break. At most one emphasis/signal span per phrase.
- Captions are timed to narration phrases via cue points; text leaves before the next
  focal element takes over.

## Honesty
- Businesses, people and apps are fictional and unbranded (e.g. "Juniper & Rye Bakery",
  "Sam Rivera"). UI shows plausible generic behaviour, not a specific vendor's product.
- If a future video reviews a real tool, it must use the tool's real behaviour captured
  legitimately, with no implied endorsement — decide with the user first.
